Send feedback Known issues

Before reporting a bug

Include the browser and device you were using, what you expected to happen, and the world link or seed if it matters. A screenshot is useful when the problem is visual.

Install or offline trouble

Reload once while connected, then try installing again from your browser's menu. If the installed version seems stale, close it, clear site data for theland.world, and reopen the site.

Purchases and refunds

The Land is currently free and does not sell anything. If paid features are introduced, the price, seller, and refund terms will be shown before checkout and linked here.
