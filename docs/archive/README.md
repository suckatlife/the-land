# Archive

Working documents from earlier phases of The Land, kept because they contain
reasoning that is not recorded anywhere else. Nothing here is current — treat
every factual claim as describing the project as it was on the file's date, not
as it is. `CLAUDE.md` in the repo root is the current front door.

## Fable runs, June 2026

Multi-window autonomous runs that built most of the atmosphere and story
systems. `BRIEF.md` is the most useful file in this folder: it is where the
project's aesthetic direction is actually written down — painterly rather than
photographic, light as a medium, calm with its own texture, the land as
protagonist — along with the two acceptance tests still used to judge changes
("can someone watch two minutes of calm and keep watching", and "can a viewer
point at where a catastrophe hit thirty seconds later").

- `BRIEF.md` — the run brief, and the aesthetic direction
- `OBSERVATIONS.md`, `PLAN.md` — the run's opening read and approach
- `WINDOW_1_NOTES.md` … `WINDOW_7_NOTES.md` — per-window summaries, each ending
  with the constants that window left tunable
- `RUN_LOG.md` — dated ship's log across the windows
- `FABLE_RUN_SUMMARY.md` — the final write-up, including dead ends

## Superseded state documents

- `STATE_2026-06-10.md` — snapshot of the simulation, June. Superseded by

- `JOURNAL.md` — first-session notes from May 2026, including the WSL setup

## Why these were not deleted

The June material was read in August to answer "what is this project actually
for" when the code alone could not say. Archived rather than removed so that
question stays answerable.
